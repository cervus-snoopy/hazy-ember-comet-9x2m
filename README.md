# One Line, One Laugh

Entry for the make.fun bounty
[One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3).

## The line

> My daughter asked where babies come from and I said 'the stork' — she asked for the tracking number.

100 characters, 19 words. One line, plain words, no setup, no signature.

## Why this angle wins

The visible field is saturated with three templates: the talking smart device
(smart fridge, smart speaker, smartwatch, phone — ten or more entries), the
meta AI-assistant joke (leaves you on read, quits first, sues for royalties),
and the Roomba (custody, union, sock). This line touches none of them. It wins
on the judge's own order:

1. **Surprise (criterion 2):** the turn is the joke — an old myth (the stork)
   collides with modern logistics (a tracking number) in the last five words.
2. **Economy (criterion 3):** 100 characters, 19 words; the setup is one
   sentence, the punchline is one phrase.
3. **Freshness (criterion 4):** no stork, no babies, no tracking number
   anywhere in the visible field — and no parenting angle at all.
4. **Clean wording (criterion 5):** it reads smoothly aloud, first read.

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), fails
loudly if the line ever leaves the 1–200 character gate, and
exits 0. No network, no randomness, no clock — the output is identical
on every run.
